# Nested probe V4
Keeps the V3 UIKit entry, scene and private file counter. A button loads a separate SwiftUI framework with an explicit C factory returning a hosting controller. Logs record the load, factory, view appearance, grid interactions and return to UIKit. The grid is an interactive diagnostic, not the real Nova launcher. No second SwiftUI.App, engine, App Group, signing account or nested guest execution. Use a new guest; verify UIKit counter, SwiftUI grid, return, close/reopen and copy log. If it fails before copying, retrieve Documents/BloomBoxDevProbeV4.log from the guest container. No main changes or release.
